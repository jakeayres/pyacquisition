`pyacquisition` is a Python package for controlling laboratory instruments and
recording scientific data. Compose your own tasks to build automated
experiments, using ready-made instruments or your own, and write only the logic
that is unique to your science. Scheduling, logging, data files, live graphing
and a full GUI all come free.

```
pip install pyacquisition
```

## 📖 Documentation

**Everything lives at [pyacquisition.readthedocs.io](https://pyacquisition.readthedocs.io)**:
installation, a step-by-step tutorial, the supported instruments, and the full
API reference.
